# Dataset Metadata

## Summary

Video sequence dataset of petrographic thin sections rotated 360° under a polarized light microscope, captured under dual illumination (**PPL** and **XPL**). Designed to train spatio-temporal models that distinguish **biotite** from **hornblende** based on their optical response during stage rotation.

| Field | Value |
| :--- | :--- |
| **Classes** | 2 (`Biotite = 0`, `Hornblende = 1`) |
| **Total Samples** | **97** segmented crystals |
| **Class Distribution** | 61 Biotite · 36 Hornblende |
| **Frames per Sample** | 72 (full 360° rotation, 1 frame every 5°) |
| **Optical Modes** | PPL (Plane-Polarized Light) + XPL (Cross-Polarized Light) |
| **Frame Resolution** | `280 × 280` px (RGB) |
| **Final Format** | PyTorch tensors (`.pt`) |
| **Primary Source** | [virtualmicroscope.org](https://www.virtualmicroscope.org) |
| **Code License** | CC BY-NC-ND 4.0 (© 2026, Ariana Ganea) |

## `.pt` Tensor Format

Each file is a PyTorch dictionary generated by `Segmentation/TF2Tensor.py`:

```python
{
    "ppl":   torch.Tensor,   # shape (72, 3, 280, 280), float32, normalitzat
    "xpl":   torch.Tensor,   # shape (72, 3, 280, 280), float32, normalitzat
    "label": int,            # 0 = Biotite, 1 = Hornblende
    "name":  str,            # ex: "I08_rot2_crystal_1"
}
```

**Preprocessing applied (PNG frames → tensor):**

| Step | Details |
| :--- | :--- |
| **Resize** | `280 × 280` pixels |
| **ToTensor** | Rescaled from `0–255` to `0.0–1.0` |
| **Normalize** | `mean = [0.485, 0.456, 0.406]`, `std = [0.229, 0.224, 0.225]` (ImageNet) |

---

## Naming Convention

Format: `<rock_name>_rot<rotation>_crystal_<id>.pt`

| Field | Description |
| :--- | :--- |
| `rock_name` | Descriptive sample identifier (e.g., `granite_leinster`, `I08`) |
| `rot<N>` | Rotation region within the same thin section (`1, 2, 3...`). A single thin section may contain multiple observation zones |
| `crystal_<id>` | Index of the segmented crystal within that region (`1, 2, 3...`) |

Example: `I08_rot2_crystal_3.pt` → third crystal extracted from the second rotation region of thin section `I08`, labeled as biotite or hornblende according to its parent directory.

## Temporal Geometry

- **72 frames** per sample → 1 frame every **5°** across 360°
- Frame `i` corresponds to angle `i × (2π / 72)` radians (`i × 5°`)
- Temporal models (`LSTM`, `Attention`, `MeanPooling`) process the full 72-frame sequence; the `StaticImage` baseline uses frame `0` only.

```
       Dataset/original_videos/<Mineral>/{PPL,XPL}/<roca>_rot<N>/

[2] Segmentation/Codi_Segmentacion.py  (interactive — SAM2)
       ↓ Manual ROI + rigid rotation mask tracking

       Dataset/segmented_minerals/<Mineral>/<roca>_rot<N>_crystal_<id>/

[3] Segmentation/TF2Tensor.py
       ↓ 280×280 resize + ImageNet normalization + serialization

       Dataset/segmented_minerals_tensor/<Mineral>/<...>.pt
```

## Class Distribution for Training

All training scripts apply **inverse-frequency class weighting** (`CrossEntropyLoss(weight=...)`) based on the dataset counts:

```python
class_counts = torch.tensor([61, 36], dtype=torch.float32)  # [Biotite, Hornblende]
weights = (1 / class_counts)
weights = weights / weights.sum()
```

Evaluation uses `StratifiedKFold(n_splits=5, shuffle=True, random_state=42)` to preserve the class ratio across all folds.
